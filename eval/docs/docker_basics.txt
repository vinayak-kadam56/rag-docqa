Docker packages an application and its dependencies into a container image. An image is built from a Dockerfile, which lists instructions such as FROM, COPY and RUN. A container is a running instance of an image. Containers share the host operating system kernel, which makes them lighter than virtual machines. Data written inside a container is lost when the container is removed, so persistent data is stored in volumes. A named volume is created with docker volume create and mounted with the -v flag. Docker Compose lets you define several services, such as a web app and a database, in one docker-compose.yml file and start them together with docker compose up. Ports are published with the -p flag, for example -p 8000:8000 maps port 8000 on the host to port 8000 in the container. Docker Hub is the default public registry where images are pulled from.

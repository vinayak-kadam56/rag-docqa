A virtual environment is an isolated Python installation that keeps the packages of one project separate from another. It is created with python -m venv .venv and activated with source .venv/bin/activate on Linux and macOS or .venv\Scripts\activate on Windows. Once active, pip installs packages only into that environment. The command pip freeze lists installed packages with exact versions, and a requirements.txt file records them so that others can reproduce the setup with pip install -r requirements.txt. Using a virtual environment avoids version conflicts between projects. FastAPI is a modern Python web framework for building APIs; it uses type hints and generates interactive documentation at the /docs path automatically. Uvicorn is the ASGI server commonly used to run FastAPI applications.

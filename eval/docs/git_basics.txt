Git is a distributed version control system. A repository stores the full history of a project. The command git init creates a new repository and git clone copies an existing one. Changes are first added to the staging area with git add and then recorded with git commit. A branch is a movable pointer to a commit; git branch creates one and git switch moves between branches. To combine work from two branches you use git merge, which can produce a merge conflict when both branches changed the same lines. The remote called origin usually points to the hosting service, such as GitHub. git push uploads local commits to the remote and git pull downloads and integrates remote changes. A .gitignore file lists files that Git should not track, for example virtual environments and secret keys. The command git log shows the commit history.
